# data/ — datasets by pipeline stage

Everything here is gitignored except `sources.yaml` and this file. Data never enters git;
provenance and hashes do. Format rules and stage schemas: [docs/standards/data.md](../docs/standards/data.md).

Line format: `- [name](path) — what it is · status · key fact`.

## Stages

Tables are Parquet, grids are Zarr. A pandera schema checks every stage boundary.

- [raw/](raw/) — original datasets, immutable, original names · gitignored, protected, junction to `E:\CLEAR 2.0\RAW Data` · written only by `scripts/intake.py`; map is [knowledge/data/INDEX.md](../knowledge/data/INDEX.md)
- [prior/](prior/) — old pipeline outputs (per-cell extracts, features, training sets, models) · gitignored, protected, junction to the Seagate (`D:\CLEAR 2.0\Cleaned Data`) · reference and golden numbers only, not a pipeline input until validated and an ADR approves reuse; map is [knowledge/data/INDEX.md](../knowledge/data/INDEX.md)
- [interim/](interim/) — lossless, UTC-normalized long tables (read scope only, no QC) · gitignored, local on C: · lossless per-dataset tables `<dataset>/pm25_hourly_raw.parquet` (`clear stations build`)
- [processed/](processed/) — analysis-ready tables and grids · gitignored, local on C: · `stations/` (QC'd hourly, registry, completeness, merged series), `grid/` (Toronto 0.1° cells, station cells)
- [features/](features/) — model inputs · gitignored, local on C: · empty until the features phase

## Provenance

- [sources.yaml](sources.yaml) — URL, query, download date, license and file hashes for every raw dataset · committed · Phase 1 sources registered
- `manifests/inventory-summary.csv` — one row per dataset folder (files, bytes, status counts) · committed · read first
- `manifests/inventory.csv` — size and sha256 of every original · local only, Grep-able · generated by `scripts/inventory.py`
- Backup of `archive/` and `data/raw/` lives on the Seagate (`CLEAR_BACKUP_ARCHIVE_DIR`, `CLEAR_BACKUP_RAW_DIR` in `.env`), checked by `/backup-check`. `data/prior/` has no second copy.
- Drives and links: `uv run python scripts/storage.py`; layout in [docs/standards/data.md](../docs/standards/data.md#storage).
