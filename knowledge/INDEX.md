# knowledge/ — text mirrors and data cards of every original

Agents read this folder instead of `archive/`, `data/raw/` and `data/prior/`. Each original
has a text mirror or a data card here. Start from the sub-index that fits your question.

Line format: `- [name](path) — what it is · status · key fact`.

## Sub-indexes

- [docs/INDEX.md](docs/INDEX.md) — text mirrors of methodology docs, one per logical doc · Phase 1 mirrors (stations, grid, data completeness, AirNow) · see that file
- [data/INDEX.md](data/INDEX.md) — data cards (and validation reports) for every dataset · Phase 1 cards · see that file

## Competitions (fenced)

Competition, pitch and video material is outside the research scope. It sits in
`archive/competitions/` and is **not mirrored**. Agents go there only when Ryan asks.
Each folder gets one line here, added by `/map-refresh`.

No competition folders mapped yet: Phase 1 files only what the stations and grid stage reads, so competition material is not filed yet. Lines appear when a later `/map-refresh` files it.

## Generated files

- `_sources.json` — maps each original path (and alias) to its mirror and the sha256 at conversion · generated by `scripts/inventory.py` from mirror frontmatter · never edit by hand
- `manifests/inventory-summary.csv` (repo root) — one row per dataset folder with status counts · committed · read first
- `manifests/inventory.csv` (repo root) — every original with size, sha256, mirror path, status · local only (gitignored), Grep-able · generated by `scripts/inventory.py`

Mirror and data-card rules: [docs/standards/writing.md](../docs/standards/writing.md).
