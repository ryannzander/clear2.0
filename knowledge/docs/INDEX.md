# knowledge/docs/ — text mirrors of the original documents

One `.md` mirror per logical doc (docx preferred over pdf). Paths are slugified: lowercase,
hyphens. Frontmatter links each mirror to its original (`source`, `aliases`, `sha256`).
Superseded versions get no mirror unless they hold unique content.

Line format: `- [slug](slug.md) — what the doc is · current|superseded · key fact`.
Group lines under `##` headings by topic or methodology part.

No mirrors yet. They appear after the first `/map-refresh` (Phase 1, from 2026-10-21).

## Images and media

PNGs and videos get a one-line description here instead of a mirror. Embedded doc images
are extracted only when a spec cites them.

Line format: `- <archive path> — what it shows · media · where it is used`.

None yet.
