# naps-hourly-pm25

## What it is
ECCC NAPS continuous hourly PM2.5, the annual national files `PM25_YYYY.csv`, 2000–2024. One row
is one station, one instrument (method code) and one local-standard-time day, with 24 hourly values.

## Time convention
- Zone: local standard time, no DST. Ontario = UTC−5 all year. Other provinces use their own
  standard offset (not needed for Toronto).
- Label: hour-ending. `H01` covers 00:00–01:00 LST; `H24` covers 23:00–24:00 LST.
- Evidence: every file header, `Note // Note,Data is hour ending local standard time`; NAPS
  Open Government record (open.canada.ca, dataset `1b36a356-defd-4813-acea-47bc3abd859b`): hourly
  concentrations "are reported as hour-ending averages in local standard time with no adjustment
  for daylight savings time".
- Observed check (2026-10-24): after HE-LST → UTC hour-beginning (start = date + H − 1 h + 5 h),
  NAPS 060445 matches AirNow 124000060445 (documented UTC hour-beginning) at lag 0: 99.6 % of
  40,016 hours equal, 2020–2024; lag ±1 h: 36 %.

## Known issues
- Missing code `-999` (file header: "-999 denotes no data available"; "Zeros are valid").
  6,097,619 cells across all years.
- 3,448 other negative cells, −1 to −33 (2,577 are −1). Not documented as flags.
- Several method codes at one site and date are separate rows (key = NAPS ID + method code + date);
  0–66 stations per year have more than one row per date.
- `PM25_2006.csv`: 1,095 exact-key duplicate rows (same NAPS ID, method, date) for NB stations
  040203, 040207, 040801; the hourly values differ in 1,009 of them. No Ontario station affected.
- Max value 5,198 µg/m³ (NAPS 090702, 2016-05-04).
- The derived xlsx drop the leading zero of the NAPS ID (`60410`); join on the CSV IDs.
