# /figure

## When
A figure issue, an experiment result that needs plotting, or a figure whose inputs changed.

## Inputs
Slug (`fig_<slug>`), data inputs (paths), intended use (internal, paper, slide, poster), size preset.

## Steps
1. Read `figures/INDEX.md`: new figure or update? Reuse an existing script as the base.
2. Write `figures/src/fig_<slug>.py` from the pattern in `docs/standards/figures.md`. Use only `clear.viz`: `use_style()`, `color(role)`, `alert_cmap()`, `preset(name)`, `plotly_template()`. No hex colors, no private rcParams. Presets: `paper-1col`, `paper-2col`, `slide-16x9`, `poster`. Maps use the one fixed projection and the Toronto/1000 km extent preset. Times shown to readers are Toronto local, labelled; data stays UTC.
3. End the script with `save_figure(fig, slug, caption=..., inputs=[...], preset=..., headline=False)`. It writes `figures/out/fig_<slug>.png`, `.svg` and the sidecar `fig_<slug>.md` (caption, what it shows, inputs + sha256, git commit, preset, headline).
4. Build: `uv run clear figures build --only <slug>` (`uv run clear figures list` shows the registry).
5. Look at the PNG with Read. Check: text legible at preset size, units in axis labels, colors from tokens and consistent with alert levels, legend does not cover data, caption matches what is drawn. Fix and rebuild until clean.
6. Headline gate: if the figure is headed for a paper, pitch or competition, the Lead shows Ryan the PNG and caption. Set `headline=True` only after his OK, then rebuild.
7. Add the line to `figures/INDEX.md`.
8. Stage; `/review` (`figures/src/` is gated). Fix findings.
9. Commit `fig: <slug>` and push. No AI attribution.

## Outputs
`figures/src/fig_<slug>.py`, `figures/out/fig_<slug>.{png,svg,md}`, INDEX line.

## Done when
- [ ] Script uses only `clear.viz`; no hex literals.
- [ ] PNG, SVG and sidecar are regenerated by `uv run clear figures build --only <slug>`.
- [ ] You viewed the PNG and it passes the step-5 checks.
- [ ] Sidecar `headline` is `false`, or `true` with Ryan's recorded OK.
- [ ] `/review` passed; pushed.

## Standards to load
- `docs/standards/figures.md` (pattern, presets, tokens, Mermaid rules).
- `docs/standards/naming-units-time.md` for axis labels and time zones.
